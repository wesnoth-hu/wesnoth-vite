# Magyar Wesnoth Közösségi Portál

## Tech Stack

1. Vite – Build eszköz és fejlesztői szerver
2. React – UI könyvtár
3. TanStack React Query – Adatlekérés és cache kezelés
4. TypeScript – Típusbiztonság
5. Firebase Authentication – Hitelesítés
6. Firebase Firestore – Adatbázis
7. Brevo – Tranzakciós és marketing e-mailek
8. Sonner – Toast értesítések
9. Zustand – Állapotkezelés
10. Zod – Séma validáció
11. Material Design Icons (MDI) + Social Media Icons – Ikonok
12. Gábor Udvari grafikái és tervei
13. Rawpixel Public Domain (CC0) hátterek
14. Battle for Wesnoth hátterek
